Add an `agentConnect` plugin for the NEAR Intents Agent API (https://api.agentsonintents.com): give every signed-in user an owner-controlled agent account on NEAR Intents — the owner signs the rules once with their wallet or passkey, and agents hold revocable `ngt_` grant tokens that only act inside the owner-signed policy. The server plugin (`agentConnect`) wraps `@near-intents-agent-api/sdk` behind a small endpoint surface — `agent/create`, `agent/intents/submit`, `agent/status`, `agent/list`, `agent/grants/issue|revoke|list` — enforcing session↔agent↔intent ownership on every route, persisting idempotency keys before sends, and storing grant tokens encrypted at rest (HKDF→AES-256-GCM, never sent to a browser). The client plugin (`agentConnectClient`, surface `client.agent.*`) signs generated intents byte-for-byte with the connected wallet — `nep413` via signMessage, `nep366` via signDelegateActions, `webauthn` via the passkey authenticator — and submits them in one `signAndSubmitIntent` call. Server types (`Policy`, `OwnerWallet`, `SignedData`, `StatusResponse`, `GrantView`, …) are re-exported from the SDK rather than re-declared. Register the plugin unconditionally; it stays dormant until a `naa_` partner API key is configured (secret `NEAR_INTENTS_AGENT_API_KEY`, optional `agentApi.baseUrl`/`timeoutMs` auth variables).
