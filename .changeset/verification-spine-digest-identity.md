Digest identity consolidation (ADR 0046 ticket 04): one module (`everything-dev/fingerprint`) owns every composition-plane identity, and the recorded fingerprint seam is closed. `deploymentFingerprint`/`pointerFingerprint` are renamed `deploymentDigest`/`pointerDigest`, and the deployment digest now derives from the pointer inputs — the pin coordinates resolution stamps onto every resolved slot (`digest` field) — plus the resolved entry coordinates, so a pointer-only republish (identical entry bytes, changed files map) moves it: the host's adopt comparison now notices such publishes instead of serving stale pins until restart, and the client soft-refresh signal moves with it. The vocabulary cutover renames every wire field the old word survived in — lockfile + boot snapshot (`fingerprint` → `pointerDigest`, schemaVersion 1 → 2; old files fail the strict parse naming the field and regenerate on the next `bos lock` / first adopt), deploy records and their summaries, the CLI contract results, the client payload (`deploymentFingerprint` → `deploymentDigest`), and `/.well-known/version` (now `deploymentDigest` + `pointerDigest`). The endpoint split also fixes the ops split-brain detector's cross-plane comparison — published pointer digest vs the host's served pointer digest (previously compared against the serving-generation digest, which never matches). The compose variant fingerprint is renamed `variantCacheKey` — it hashes dev mtimes, a cache key, not an identity.
